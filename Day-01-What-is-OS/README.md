# 🖥️ Day 01 - What is an Operating System?

## Objective
To understand what an Operating System is, the difference between single-user and multi-user systems, and the interface types used to interact with them.

---

## What is an OS?
An **Operating System (OS)** is system software that:
- Manages computer hardware
- Provides basic services for applications
- Acts as an interface between the user and hardware

---

## Types of Machines

### Single-User Machine
- Designed for **one user at a time**
- Focuses on providing resources to a single user
- Examples: PC, Smartphone, Tablet, Gaming Console

### Multi-User Machine
- Allows **multiple users** to access the system simultaneously or at different times
- Examples: Rack Servers, Blade Servers

---

## Interface Types

| Interface | Description |
|-----------|-------------|
| **GUI** (Graphical User Interface) | Visual, mouse-driven interface |
| **CLI** (Command Line Interface) | Text-based, keyboard-driven interface |
