# 🐧 Day 02 - Unix and Linux History

## Objective
To understand the origin of Unix, how Linux was born, and the key differences between Unix and Linux.

---

## What is UNIX?
Unix is a family of operating systems that originated in the **late 1960s at Bell Labs** (AT&T).
- Highly portable, scalable
- Provides a robust set of tools for computing tasks
- Created by **Ken Thompson** and **Dennis Ritchie**

---

## Key Features of Unix

| Feature | Description |
|---------|-------------|
| Multi-user & Multi-tasking | Multiple users and programs run simultaneously |
| CLI | Users interact via text-based commands |
| File Hierarchy | Files organized under root directory `/` |
| Everything is a File | Devices and network resources treated as files |
| Shell | Command interpreter (Bash, Zsh, Csh) |
| Pipelines & Redirection | Connect commands via `|` operator |
| Portability | Runs on wide range of hardware |
| Security | User/group permissions control access |

---

## The Birth of Linux

- **Created by:** Linus Torvalds in **1991**
- **Source Model:** Free and open-source (GPL license)
- **Kernel:** Unix-like kernel following Unix design principles
- Linux itself is only the **kernel** — the core that manages hardware

> 🌐 Official Kernel: https://www.kernel.org/

### Linux Distributions (Distros)
Complete OSes built using the Linux kernel:
`Ubuntu`, `Fedora`, `Debian`, `CentOS`, `Rocky Linux`, and many more.

---

## Unix vs Linux

| Feature | Unix | Linux |
|---------|------|-------|
| Licensing | Proprietary | Open-source |
| Kernel | Varies | Monolithic Linux kernel |
| Availability | Servers, workstations | Servers, desktops, smartphones, etc. |
| GUIs | Primarily CLI | Various GUI options |
| Community | Smaller, closed | Large, active, open |

---

## GNU Project
GNU is a free software operating system. The combination of **GNU tools + Linux kernel** creates a complete OS — often called **GNU/Linux**.
